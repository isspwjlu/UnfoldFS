# 缺陷超胞算例：体相 1T-TaS2 的 3×3×1 超胞 + S 空位（Ta9S16）

回答的问题：**无序（点缺陷）破坏平移对称性后，反折叠谱还剩下什么？**
与 `scripts/cdw/` 的 CDW 算例互补 —— CDW 是**有序**的对称性破缺（超胞里
每个原胞副本的畸变相同），缺陷是**无序**的（9 个副本的局域环境各不相同）。

## 文件

| 文件 | 作用 |
|---|---|
| `build_defect_tas2.py` | 建结构：体相原胞 → 3×3×1 超胞 → 去掉 2 个 S ⇒ Ta9S16；输出 PRIMCELL / TRANSMAT / 完美超胞 / 缺陷超胞，并自检原子副本匹配 |
| `fix_lattice.py` | 弛豫后用**参考晶格** + CONTCAR 的离子位置重建 POSCAR（晶格必须与 TRANSMAT 自洽） |
| `setup_defect_tas2.sh` | 服务器端：弛豫、静态计算、网格生成、作业提交、反折叠 |
| `compare_defect.py` | 对比三个算例的费米面（重合率）与 E_F 处谱权重 |

## 流程

```bash
# 1. 本地建结构（初始参数: a = 3.36006 A, c = 5.98212 A, Ta-S = 2.58 A）
python scripts/defect/build_defect_tas2.py --out-dir <dir> --seed 20261123

# 2. 上传 <dir> 里的 PRIMCELL.vasp / TRANSMAT.in / sc3x3x1_*.vasp 到服务器
#    的 .../defect/struct/，然后:
bash setup_defect_tas2.sh relax_prim       # 原胞全弛豫 (ISIF=3)
# 3. 下载 relax_prim/CONTCAR -> PRIMCELL_relaxed.vasp, 再用 --from-primcell
#    重建两个超胞 -> 上传 sc3x3x1_perfect_relaxed.vasp / sc3x3x1_defect.vasp
bash setup_defect_tas2.sh relax_defect     # 缺陷超胞离子弛豫 (ISIF=2, 固定晶格)
# 4. 弛豫完 -> fix_lattice.py 固定晶格 -> sc3x3x1_defect_relaxed.vasp -> 上传
bash setup_defect_tas2.sh static_prim      # 原胞 (直通模式)
bash setup_defect_tas2.sh static_perfect   # 完美 3x3x1
bash setup_defect_tas2.sh static_defect    # 缺陷 Ta9S16
bash setup_defect_tas2.sh unfold           # 三个算例的反折叠
```

## 关键设定

- **赝势**：用用户自己的 `Ta_pv`（`$WORKDIR/vasp_work/TaS2/A/scf/POTCAR`，
  含 5p 半芯）。`potpaw_PBE.64` 的 Ta 是 6s5d 半核实（ZVAL=5），
  Ta 的 5p 半芯被当成芯 ⇒ 带能整体偏高 25 eV 量级。
- **网格**：`unfoldfs gen --grid 48 48 6`。P1 必须是 3 的倍数
  （超胞 BZ 只被 P1/3 个点采样，否则网格自洽性检查失败）。
  超胞 k 点 = (48/3)×(48/3)×6 = 1536。
- **原子对应**：缺陷超胞弛豫后离子偏离理想格点，`build_atom_copies` 的整数
  平移判据（容差 1e-6）会失败 ⇒ 反折叠时 `--supercell` 要用**理想位置**的
  缺陷超胞（`SUPERCELL_IDEAL.vasp`），相位项用的是**原胞**原子的位置，
  所以这样匹配在物理上是正确的。

## 踩过的坑

1. **超胞复制必须以原胞格矢平移**（笛卡尔 `p + n1·a1 + n2·a2`）。
   用分数坐标平移会让原子副本匹配直接失败。
2. **不能用 `np.mod(x, 1.0)` 折回胞内**：它把 −0.005 变成 0.995，
   同一个物理位置（0 与 0.995 等价）会被当成相差一个晶格常数。
   用居中 `x - round(x)`，比较位移时用周期距离。
3. **`ISIF` 默认是 1**（只弛豫离子、固定晶格）。要弛豫晶格必须显式写
   `ISIF = 3`，否则应力收敛判据会被跳过、晶格一动不动。
4. 登录节点只有 1 个核 ⇒ 反折叠必须提交到计算节点。
5. **`/tmp` 是节点本地的**：`sbatch` 跑的作业看不到登录节点的 `/tmp`，
   脚本要放在共享目录（`$B/`）里并用绝对路径调用。
6. **弛豫后的晶格有 ~2.6e-5 Å 的数值倾斜**（应力有限差分的噪声），
   会让 spglib 在 symprec=1e-5 下只认出 **4 个**点群操作而不是 12 个。
   用 `idealize_lattice.py` 把原胞与超胞的晶格**一起**理想化成六方
   （保持分数坐标不变）⇒ 恢复 12 个操作。
   ⚠ 原胞与超胞必须一起改：原子副本匹配的整数平移容差只有 1e-6。
   ⚠ 理想化后 `grid_map.npz` 里记的 b_prim 与结构不自洽 ⇒ 必须用理想化
   的结构**重跑一次 `unfoldfs gen`**（重写的 KPOINTS 内容不变）。
   实测：4 个操作与 12 个操作在 kz=0 平面上生成同一个面内对称群
   （C3 与 C6 组合即六重），结果实质相同 ⇒ 理想化是**稳健性**改进，
   不是结果的修正。

## 实测结果（2026-11-23）

结构：体相 1T-TaS₂，弛豫后 a = 3.37549 Å、c = 6.46178 Å、Ta–S = 2.4807 Å；
两个 S 空位分属两个 S 子晶格、不同层，最短周期距离 5.167 Å；
离子弛豫（固定晶格）后 Ta 最大位移 0.517 Å、S 最大 0.265 Å。
k 网格 48×48×6（Γ 中心），σ = 0.06 eV，NBANDS = 120。

| 指标 | 完美 3×3×1 (27 原子) | 缺陷 Ta9S16 (25 原子) |
|---|---|---|
| 单-G 主导度 | **0.9705** | **0.3956** |
| 相位约定 | s1 = −1, s2 = −1 | s1 = −1, s2 = −1 |
| E_F (VASP 绝对零点) | 4.543657 eV | 3.915548 eV |
| A(k, E_F) max | 0.12372 | 0.03232 |
| FS 上的谱权重 w(k) 中位 / max | 0.0815 / 0.1153 | 0.0359 / 0.0699 |
| FS 曲线段数 | 2736 | 3294 |

缺陷 vs 完美：FS 重合率 **51.34 %**（0.5 格判据），点到曲线距离
中位 0.498 格 / 最大 2.88 格；ΔA(k, E_F) 最低 −0.11004、最高 +0.01518。

⇒ **缺陷不重排费米面（六重星形的骨架保留），而是把它模糊掉**：
E_F 处的谱权重降到约 1/4，曲线碎成大量片段，单-G 主导度从 0.97 掉到 0.40。
这与 CDW 的"重构"形成对照（CDW 开了伪隙 ⇒ 费米面被重排）。

对称性核对（`check_fs_symmetry.py`）：完美 3×3×1 的几何残差最大 0.96 格、
颜色残差 4.2e-17 —— 与论文单层基线（0.75 格）同量级，是该度量在
48×48 网格下的正常水平，不是本算例特有的问题。

### 为什么图上 BZ 边界有一圈短段（用户 2026-11-23 提问）

**现象**: 体相算例的费米面在六边形边界上留下一圈**短段**，单层算例没有。

**机制**（已实测定位）:
- 体相 1T-TaS₂ 的费米面**叶尖朝 M′ 方向**伸出到 |k| = **1.0816 /Å**；
  第一 BZ 在该方向的内切半径（边中点）= **1.0747 /Å**
  ⇒ 叶尖**越过边界约 0.007 /Å**（0.16 个格点）。
- 画费米面时场在分数坐标上平铺 3×3 再取零等值线, 然后把每条曲线
  **折回**第一 BZ（周期折叠）⇒ 越界的那一小段被折回到边界**内侧**并被
  `split_at_jumps` 切开 ⇒ 图上表现为贴在六边形边界上的短段。
- 单层的费米面最大 |k| = **0.9270 /Å** < 内切半径 1.0781 ⇒ 完全在 BZ 内 ⇒ 无短段。

**不是"幽灵"**（判据: 圈上的 A(k,E_F) 若为 0 则是假象）:
- 完美 3×3×1 的 2736 段里, **A(k,E_F) = 0 的段数 = 0**;
  所有段的 A(k,E_F) 中位 0.0343（全局 max 0.1237 的 28 %）;
  段长中位 0.72 格, 与单层基线（0.76 格）同量级 ⇒ 全部是真费米面。
- M、K 点的 A(k,E_F) = 0（两个体系都是）⇒ 费米面**不**穿过 M/K 点,
  只是叶尖越过 M′ 附近的边界。

**顺带的发现**: 体相 FS 比单层**大 17 %**（1.0816 vs 0.9270 /Å），
而晶格只差 0.3 %（a = 3.37549 vs 3.3649 Å）⇒ 这不是晶格效应，
而是能带本身不同 ⇒ 指向**赝势口径差**（单层用半核实 Ta，
体相用 Ta_pv）。见 [[project_pseudopotential_consistency]]。
⇒ 图注里要写明"叶尖越过第一 BZ 的边界，被周期折叠切开"。



### ★ 费米面在"腰"处被整段切断 —— 根因与修法（2026-11-23 用户截图指出）

**症状**: 1T-TaS2 的六重星形 FS, 每条臂在 |k| ≈ 0.25（体相）/ 0.29（单层）
处**断成两截**, 缺口肉眼可见。

**根因**（不是画法 bug, 是**提取方法**的局限）:
1T-TaS2 是**嵌套**体系。嵌套向量处有两条带在 E_F 附近交换。
`plot_fs.peak_energy_field` 用 `np.argmax` 取窗口内**最高**的峰 ⇒ 在嵌套处
主峰跳到**另一条**带上 ⇒ 该 k 处 E*(k) 偏离 E_F 达 ~0.09 eV ⇒
`E*(k) − E_F = 0` 的等值线在那里**不存在** ⇒ 曲线整段消失。
- E*(k) 在对称相关点上也不一致（一个 +0.09, 另一个 −0.02）⇒
  **轨道平均**后归零 ⇒ 曲线恢复连续。
- 实测：修正前体相 54 个断点（全在 |k| = 0.25）；修正后 **0 个**。

**修法**（两处, 都在 `scripts/figures/plot_fs.py`）:
1. `panel_data` 里把**脊顶能量场 E*(k) 也做轨道平均**（以前只平均权重）,
   并用对称化后的 E* 去取带权重;
2. `symmetrize` 改成 **NaN-safe**: 只在**有限**的像之间平均, 所有像都是 NaN
   时保持 NaN（原来写 0 ⇒ "没有峰"被当成"峰在 E=0", 随后被闸门整片删掉
   ⇒ 单层 1T-TaS2 直接变 0 段）。

**对论文已有图的影响**: 单层 96×96 数据**完全不变**（段数 2196/2196/3606、
重合率 100.00%、权重中位 0.6535/0.2570/0.3496 都一样）⇒ 论文现有的
图 4/5/7 不受影响；只有**体相**（嵌套更强）受益。

⚠ **别用绝对阈值判重合率**: `cKDTree` 的距离是 2π/Å, 要除以网格间距
才是"格"。用 0.5 /Å 的绝对阈值会把体相的 45.56 % 误报成 100 %。

### ★ 臂的末端被 BZ 边界"切断" —— 根因与修法（同一批截图指出, 原胞面板也一样）

**症状**: 六条臂的末端在第一 BZ 的边界处断开, 边界内侧还留着一圈
贴边的碎片, 臂与碎片之间有一段空隙 ⇒ 看起来像"费米面被一条线切断"。

**根因**: `zero_contours` 用 `fold_to_bz` **逐点**折叠 —— 越过 BZ 边界的
连续曲线被**逐点**翻到边界内侧 ⇒ 末端与碎片之间出现空隙。
（`fold_to_bz` 逐点做笛卡尔 Voronoi 折叠, 保证每个点都在第一 BZ 内,
代价就是把连续的曲线撕开。）

**试过的修法, 最终**否决**: 改成"按段整体平移"（先按接缝切段, 每段选
一个共同的平移量 = 逐点最近像的**众数**）⇒ 曲线确实连续了, 但每段独立选
平移量 ⇒ **破坏了点群协变性 ⇒ 费米面变得不对称**（用户 2026-11-23 指出,
实测确认）。

**最终决定**: **对称比连续更重要** ⇒ 保留逐点 Voronoi 折叠
（`fold_to_bz`, 对每个点独立选最近像 ⇒ 与点群协变）, 并
- 在图里画出**暗蓝色**的 BZ 边界虚线（`PALETTE["bz_edge"]`, 与论文图 4/5/7
  一致; 浅灰 `#CFCECE` 在深底上像"一圈白线", 用户 2026-11-23 指出）；
- 图注里写明"叶尖越过第一 BZ, 越界部分由周期折叠带回, 所以等值线在
  边界处结束"。
⇒ 论文现有图 4/5/7 完全不变（重合率 100.00%、权重中位 0.6535/0.2570/0.3496）。

### ★ 赝势统一（用户 2026-11-23 决定）

体相三个算例改用**单层 1T-TaS₂ 那套赝势**（`potpaw_PBE.64` 的 `Ta` 6s5d **半核实**
+ `S`），而不是用户的 `Ta_pv`。理由：单层与体相的 FS 半径必须一致，
否则两幅图并列时形状不同、读者无法比较。

⚠ 半核实 Ta 把 5p 半芯当芯（物理上 `Ta_pv` 才对，之前实测带能差 25.6 eV、
展开主导度 0.457 → 0.273）⇒ 这是"图与口径一致"优先的取舍，已在 fact_sheet 标注。
CDW 算例仍用用户的 `Ta_pv`。
⚠ 上传 .sh 到服务器前**必须转 LF 行尾**（Windows 编辑会把 CRLF 带进去，
服务器 bash 会报 `set: -\r: invalid option`，整段脚本静默失效）。

### ★ "FS 穿出第一 BZ"是画法的硬骨头

1T-TaS₂ 的费米面**可以**穿出第一 BZ（半核实 Ta: FS_max/BZ内切半径 = 0.860 ⇒
在 BZ 内；Ta_pv 的体相: 1.0064 ⇒ 穿出）。穿出后画在单个 BZ 里会出现
- 边界附近一圈**碎片**（越界段被周期折叠带到对面边界内侧），
- 臂的末端与碎片之间隔着**整整一个 BZ 高**（2.1–2.25 /Å）的空隙
  ⇒ 看起来像"费米面被一条线割断"（用户 2026-11-23 指出）。

**为什么 fig.4(a) 是对的而 fig.9(a) 不对**: 单层的 FS 完全在 BZ 内（比值 0.86）
⇒ 没有碎片也没有断口；体相（Ta_pv）穿出 ⇒ 两者画法一样，只是数据不同。

**试过并否决的画法**（都会破坏点群协变性，论文的核心卖点不能动）:
| 画法 | 间隙 | 几何对称残差 | 结论 |
|---|---|---|---|
| 逐点 Voronoi 折叠（现用） | 有（47–95 格） | 0.7–1.5 格 | 保留: 对称 ✓ |
| 按段整体平移 | 0 | 8.8 / 58.9 格 | 否决: 不对称 ✗ |
| path 级众数折叠 | 0 | 8.8 / 58.9 格 | 否决: 不对称 ✗ |
| 沿曲线连续性优先（tol=0.3） | 0 | 8.8 格 | 否决: 不对称 ✗ |
| 剔除"紧贴边界的段" | 0 | 0.18 格 | 否决: 会把**臂的末端**一起截短 ✗ |

⇒ 结论: **对称 vs 连续不可兼得**（几何事实: 一条穿出 BZ 的曲线，在单个 BZ 内
必然断）。统一赝势让 FS 回到 BZ 内 ⇒ 问题自动消失。

**如果将来还要处理 FS 穿出 BZ 的体系**: 用**连通分量**区分碎片与主体
（比"紧贴边界"判据好: 后者会把臂的末端一起截短）。
实测: 体相 2736 段分成 38 个分量 = **6 个大分量**（每条 353–476 段、
长度 257–260 格, 即六条臂）+ **12 个小分量**（各 **1 段**、长度 0.1–0.7 格,
即碎片）；单层 96×96 则是 6 个大分量（865–1232 段、~680 格）+ 9 个小分量
（各 1 段、0.2–1.0 格）⇒ 碎片与主体的长度差**三个数量级**, 判据很干净:
剔除"孤立且长度 < 2 格"的分量即可, 且不会碰到臂的末端。

### ★ spglib 的 symprec 与弛豫后原子位置的 1e-5 偏差

VASP 弛豫后 S 的分数坐标会偏离理想的 (1/3, 2/3) 约 **1.1e-5**（数值噪声），
恰好越过 spglib 的 `symprec=1e-5` ⇒ 点群从 **12 个操作掉到 4 个**
⇒ 轨道平均只恢复部分对称性 ⇒ 费米面不对称。
单层的 `PRIMCELL.vasp` 是精确的 1/3 所以没暴露。
⇒ `build_defect_tas2.py --symmetrize-atoms` 把原胞原子位置对称化到严格 D3d
（Ta 在 (0,0,0)，S 在 (1/3,2/3,z) 与 (2/3,1/3,1-z)），超胞由它复制而来 ⇒
自然对称。`idealize_lattice.py` 只负责晶格理想化（两者要**一起**改，
否则原子副本匹配失败）。
