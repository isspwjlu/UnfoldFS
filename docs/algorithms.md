## 1. 折叠/展开的行–列约定

### 1.1 四条关系式

全模块统一（`unfoldfs/geometry.py` 模块头 + `Transform` 类）：

| 量 | 关系式 | 说明 |
|---|---|---|
| 超胞晶格 | `A_sc = M · A_prim` | **行约定**：M 的行是原胞基矢的整数组合 |
| 超胞倒格矢 | `B_sc = (M⁻¹)ᵀ · B_prim` | 由 `A_sc·B_scᵀ = 2πI` 推得 |
| 原子位置（直接空间） | `r_prim = r_sc · M` | **不转置** |
| 波矢（倒空间） | `k'_prim = (K + G) · (M⁻¹)ᵀ` | **转置** |

其中 `A_prim` / `A_sc` 的行 = 实矢量（Å），`B_prim` / `B_sc` 的行 = 倒矢量
（含 2π，单位 2π/Å），`M` 为整数 3×3 变换矩阵，`K` 是超胞分数坐标，
`G` 是候选折叠矢量（§4、§5），`k'_prim` 是原胞分数坐标。

### 1.2 为什么倒空间要转置：spglib 用**列向量**约定

spglib 存的对称操作是列向量形式 `x' = R·x + t`（T2 F5 / G1 两条独立实测）：

```
列约定 x' = R x : 12/12 ops map the primitive atoms onto themselves
行约定 x' = x @ R:  4/12 ops map the primitive atoms onto themselves
```

判别力更强的一次（用**转置不在群内**的结构，避免"群对转置封闭"时两种约定都能过）：

```
非约化六方基+石墨烯: n_ops=24 | 列约定 24/24 | 行约定 8/24
MoS2 原胞(fixture):  n_ops=12 | 列约定 12/12 | 行约定  4/12
```

⇒ spglib 的 R 是**列向量矩阵**（`x' = R x`）。于是：

* 作用到**行向量** k 上要转置：`k' = k·Rᵀ + t`（`SymmetryOps.apply`）；
* 超胞基底下的旋转是 `M⁻ᵀ · R · Mᵀ`（不是 `M·R·M⁻¹` —— 那是行向量约定下的写法）；
* 整数性判据即 **`M⁻ᵀ · R · Mᵀ ∈ Z³`**（§2）。

### 1.3 反例：对称 M 测不出差别，非对称 M 会暴露

⚠ 对称 M（fixture 的 `M = diag(3,3,1)`）下 `M⁻ᵀRMᵀ`、`M R M⁻¹`、`M⁻¹RM`
**三者恒等**，现有测试无法区分 ⇒ **任何涉及行/列约定的回归测试必须用非对称 M**（T2 G6）。

用笛卡尔几何真值（"该旋转是否把超胞晶格映回自身"，与分数约定无关）作裁判，
MoS2 原胞的 D3h 12 个操作（T2 F5）：

| M | 几何真值 | `M⁻ᵀ·R·Mᵀ`（本实现） | `M·R·M⁻¹`（旧） |
|---|---|---|---|
| `[[1,-1,0],[1,2,0],[0,0,1]]`（√3 型，C3 相容） | 保留 **12** | 保留 12，**逐个吻合 True** | 只保留 **4** ❌ |
| `[[2,1,0],[0,2,0],[0,0,1]]`（C3 不相容） | 保留 **4** | 保留 4，**逐个吻合 True** | 保留 4，集合不吻合 ❌ |
| `[[3,0,0],[0,3,0],[0,0,1]]`（对称，fixture） | 保留 **12** | 保留 12，吻合 True | 保留 12，吻合 True（**测不出差别**） |

在 **D6h 的 24 个操作**（六方石墨烯原胞，含奇数阶 C3 ⇒ `Rᵀ = −R` 的情形两种写法无法区分）
上，莫尔型超胞把差别放大得更狠（T2 G2）：

```
60° 莫尔型 M=[[1,1],[-1,2]] (det=3)
  物理真值保留 8/24
  M R M^-1   (行向量写法) 保留 24/24  <- 严重错(把被剪切破坏的六重对称全留下)
  M^-1 R M   (旧实现)     保留 12
  M R^T M^-1              保留  8/24  <- 对
```

`M Rᵀ M⁻¹` 与 `M⁻ᵀ R Mᵀ` 互为转置（`(M Rᵀ M⁻¹)ᵀ = M⁻ᵀ R Mᵀ`），整数性完全等价 ⇒
给出同一筛选结果 —— 两式描述的是**同一个物理判据**，实现取后者。

### 1.4 `resolve_transform`：运行时自动探测 TRANSMAT 的约定

`geometry.resolve_transform` 依次尝试 `cand = M` 与 `cand = Mᵀ`，判据是
**`cand @ prim.lattice == sc.lattice`**（`atol = 1e-4`）；两者都不匹配就报错
（"TRANSMAT/POSCAR/PRIMCELL 不自洽"）。⇒ 用户手里的 TRANSMAT.in 是行约定还是列约定
**不用自己判断**，工具会探测并统一到行约定 `A_sc = M_eff · A_prim`。

## 2. 公共对称集的筛选判据

### 2.1 判据只有旋转

```
保留 ⇔ M⁻ᵀ · R · Mᵀ ∈ Z³
```

该式保证"这个旋转把超胞晶格映到自身"（否则它不是超胞的对称操作）。

### 2.2 平移**不参与**筛选 —— 为什么

spglib 给的平移 `t` 是**模原胞格矢的代表元**：同一个对称操作，spglib 可能返回
`t = (1,0,0)` 而不是 `(0,0,0)`；C3² 的代表元正是 `(1,0,0)`（数值上 0.999999999）。
若拿它去筛 `t·M⁻¹ ∈ Z³`，会**误删 C3²**，得到 8 个**不成群**的操作
（C3 在集合内、C3² 不在）。而 `A(k,E)` 对原胞点群的**整个**平移不变，
平移只需是原胞晶格平移（spglib 已保证）⇒ 无需再筛。

实测（MoS2 3×3×1，原胞 12 个操作 ⇒ 公共对称集 **12 个**，不是 8）（T2 §5.1）：

```
简报原文判据: n_ops=8, 复合不封闭的对数=16 -> 不成群
本次实现     : n_ops=12, 复合不封闭的对数=0 -> 成群
泛点轨道大小: 简报=8  本次=12   (D3h 群阶 12 -> 完整轨道应为 12)
```

三条**互相独立**的证据：

1. **非群性实测**：见上（8 个时复合不封闭的对数 = 16；12 个时 = 0）。
2. **穷举原子映射**：把超胞 27 个原子逐一检查，原胞的 12 个操作**全部**把超胞
   原子集映回自身（3×3 超胞与 C3 相容：3a₁→3a₂ 仍在超胞格矢内）。
3. **直接对超胞跑 spglib**：`get_symmetry(POSCAR)` 给 **108 个操作 = 12 个旋转 ×
   9 个平移**，旋转集合与原胞的 12 个**完全相同** ⇒ 按"原胞操作集 ∩ 超胞操作集"
   应得 12。

补充实测（T2 F3；该次测量用的是 Ruling-7 时期的判据 `M⁻¹RM ∈ Z³`，
对 fixture 的**对称** M 它与最终判据 `M⁻ᵀRMᵀ` 恒等，见 §1.3）：

```
n_ops = 12
rotation criterion M^-1 R M integer, all hold: True
generic-point orbit size: 12 (expected 12)
every op maps the 6x6x1 grid onto itself: True
all 12 ops map the 27-atom supercell onto itself: True
```

### 2.3 平移的数值硬化

spglib 的平移代表元带 ~3e-8 的浮点残差（`t = 0.9999999999999999` 与 `0` 等价但
`≠ 0`）。`geometry._harden_translation` 把它归一化到 `[0,1)³` 并把接近 1 的分量
吸附到 0；否则下游 `int(mod(t·n,1)·n)` 式的写法会**静默错一格**。

## 3. 网格生成与 k 点去重

### 3.1 流程

均匀原胞网格 → 对称轨道分解（IR 点）→ **满网格点折叠到超胞 k** → 去重。

* 网格点：`gamma` 在 `i/n`，`mp` 在 `(i+1/2)/n`（`grid.primitive_grid_points`）。
* 折叠：`K = k'·Mᵀ (mod 1)`。
* **去重键 = 满网格折叠后的不同值**（**不是** IR 点的像）。

### 3.2 为什么去重键不能用 IR 点的像

"IR 点的像"只覆盖一部分超胞 k（一个对称轨道内的点会折到**不同**的超胞 k 上），
剩下那些超胞 k 对应的满网格点**无法表示成 `(k_super[k]+g_j)·M⁻ᵀ`** ⇒ 下游展开必然失败。
实测（T3 §7.2，fixture `M = diag(3,3,1)`，det = 9）：

| 网格 | 满网格点数 | IR 点数 | IR 方案的不同超胞 k | 满网格折叠的不同超胞 k | IR 方案下"找不到 (k,G) 覆盖"的满网格点 |
|---|---|---|---|---|---|
| 6×6×1 | 36 | 10 | 4 | **4** | 0 |
| 12×12×3 | 432 | 62 | **30** | **48** | **162 / 432** |

⇒ 12×12×3 时 IR 方案只覆盖 30/48 个超胞 k，另外 18 个超胞 k 没有 IR 代表点，
它们对应的 **162 个满网格点**在 IR 方案下无法表达。

### 3.3 权重与自洽条件

* `n_k = n_points / det(M)`（3×3×3 网格、det=3 ⇒ n_k = 27/3 = 9）；
* `k_weight[k]` = 折到该超胞 k 的**满网格点数**；
* **`Σ 权重 == 满网格点数`**（硬自检）。

实测（T3 §7.5）：

```
=== P=(6,6,1) n_points=36 n_ir=10 n_k=4 rows=4 ===
weight sum=36.0 (n_points=36)  weight set=[9.0]
=== P=(12,12,3) n_points=432 n_ir=62 n_k=48 rows=48 ===
weight sum=432.0 (n_points=432)  weight set=[9.0]
```

⇒ KPOINTS 里写的是**去重后的超胞 k**：6×6×1 从 10 行降到 4 行（2.5× 更少 k 点），
12×12×3 从 62 行降到 48 行。这样做**不依赖**"VASP 不对显式 k 点表去重"这一
未强制的假设（该假设本身在 §12 有实测支撑，但流水线不建在它上面）。

### 3.4 网格与超胞的自洽守卫

`n_points == n_k · det(M)` 是**硬守卫**：网格与超胞不自洽（网格点数不是
`comm(M⁻¹)` 的倍数）时，折叠后每个超胞 k 上的网格点数不等于 det(M)，扩展在数学上
无定义 ⇒ 报错而不是给一个"看起来能用"的费米面（T6 §5.3）。

## 4. 候选折叠矢量 G 的搜索范围

### 4.1 候选的定义与界

候选折叠矢量 `g` 满足 `g·(M⁻¹)ᵀ ∈ [0,1)³`（即把 `(K+g)` 折回原胞第一布里渊区），
恰 `det(M)` 个。等价写法 `g = f·Mᵀ`（`f ∈ [0,1)³`）⇒

```
g_i = Σ_j f_j · M_ij ,  f_j ≥ 0
⇒ g_i ∈ [ Σ_j min(0,M_ij) , Σ_j max(0,M_ij) ]     ← M 第 i 行的行和界
```

**搜索范围 = M 的行和**（逐轴向外扩一格作浮点余量）。

### 4.2 旧界 `max|M|+2` 的失败率（向量化复刻，seed 20261117，每档 300 个随机非奇异整数 M）

| 元素区间 | 旧界（`max\|M\|+2`）失败数 |
|---|---|
| `[-3, 4)` | 24/281（**9%**） |
| `[-5, 6)` | 105/295（36%） |
| `[-10, 11)` | 217/297（73%） |
| `[-30, 31)` | 276/298（**93%**） |

失败率随 `|M|` 增大 —— 恰好是**莫尔型超胞**的典型尺度。

### 4.3 换成行和界之后

* 825 个随机整数 M（元素 `[-30,31]`，seed 20261117）：**823/823 通过，失败 0**
  （另 2 个是奇异矩阵，不参与），耗时 9.4 s；
* 对称 M 与 `unfold.candidate_g_for_k`（K=0）的分数值集合 **60/60 完全一致**；
* 与**暴力宽范围搜索**对拍（单矩阵，R = ±120）：`M = [[10,10,0],[0,10,0],[0,0,1]]`
  及其转置各 100 个候选，与暴力真值**集合逐个相同**。

确定性回归例（T2 H2）：`M = [[10,10,0],[0,10,0],[0,0,1]]` ⇒ 候选满足
`g1 ∈ [0,10)`、`g0 − g1 ∈ [0,10)` ⇒ **`g0` 最大 18**，已超旧界 `max|M|+2 = 12`；
旧实现只找到 79/100 ⇒ 抛错，新实现 100/100 ✓。

> 注：T5 §3 记录的 "300 个随机 M 中 91/825 次抛错" 对应的是**小元素**区间
> （与上表第一行 ~9% 同量级）；`|M|` 越大失败率越高。

### 4.4 两处界必须保持一致

`geometry.candidate_g_vectors`（全局候选集）与 `unfold.candidate_g_for_k`（逐 k 候选集）
必须用**同一个**物理界（行和）。改其中一处必须同步另一处 —— 对称 M 下两者结果
必须完全一致，已有断言锁住这一点（T2 H6）。

## 5. 候选 G 必须**按 k 逐点计算**

### 5.1 陷阱

`candidate_g_for_k(k_super_frac, m_eff, m_inv_T)` 给定**一个**超胞 k，返回使
`(K+g)·M⁻ᵀ` 落在原胞第一布里渊区的整数 g（恰 det(M) 个）。

一般 M 下候选集**随 K 平移**：候选**个数**恒为 det(M)，但**成员**会变 ⇒ 与全局
`grid_map.gset` 的成员不同 ⇒ **索引 `j` 不同 ⇒ 静默选错带**（不报错，只是结果错）。

实测（T3 §7.6，`M = [[2,1,0],[0,2,0],[0,0,1]]`）：300 个随机 k 里有 **164 个**
的候选集与全局 `gset` 不相等（k = 0/1 成员相同但**顺序**不同，k = 2/3 成员不同）。

### 5.2 为什么 fixture 掩盖了这个陷阱

fixture 的 `M = diag(3,3,1)` 恰好与 K 无关（`gset` 对任意 k 都相同）⇒ 逐 k 计算与
用全局 `gset` 在 fixture 上**结果完全一样**，测不出差别。

真正兜住它的是 `expand.expand_to_full_grid` 的**自检②**（用 `unfolded.k_cand`
交叉核对候选索引）。负向测试（monkeypatch `candidate_g_for_k` 返回逆序候选，
分数值集合不变、只是索引错位）实测报错（T6 §4）：

```
ValueError: 候选索引与展开结果不一致: 满网格点 0 命中的候选与其原胞 k
坐标相差 4.71e-01 —— 展开时用的 k 列表顺序必须与 grid_map.k_super 一致,
否则会静默取错带
```

⇒ `expand.py` **从不**读 `grid_map.gset`，永远逐 k 调 `candidate_g_for_k`。

## 6. Popescu 投影展开公式与"副本平均"

### 6.1 公式与各项含义

（Popescu, PRL 104, 216401 (2012)；本实现移植自仓库根已实测验证的原型 `unfold_procar.py`）

```
p_i(lm) = (1/N_i) · Σ_T c_{i+T,lm} · exp(s1·i·(k'−K)·T)      副本相位还原平均
W(k')   = | Σ_i exp(s2·i·k'·r_i) · Σ_lm p_i(lm) |²            候选 G 上的谱权重
```

* `c_{i+T,lm}`：PROCAR 里第 `i+T` 个超胞原子、轨道 `lm` 的**复投影系数**
  （晶胞周期规范，不含 `e^{iK·R}`）；
* `T`：该副本相对原胞原子的**原胞格矢平移**（整数向量）；
* `N_i`：原胞原子 `i` 在超胞里的副本数；
* `exp(s1·i·(k'−K)·T)`：**副本相位还原因子** —— 把各副本的相位差折回同一参考点；
* `exp(s2·i·k'·r_i)`：Bloch character 的**原子相位因子**（`r_i` 是原胞原子的笛卡尔位置）；
* `W(k')`：把该超胞态投影到候选原胞 k' 上的**谱权重**（非负，实数）。

实现（`unfold._weight_matrix`）用一次 `einsum` + `add.reduceat` 完成全部
(候选, 带, 原子, 轨道) 的副本平均。

### 6.2 副本复值**不可假设相同** —— 必须做相位还原平均

实测（T4 §5.1，扫描 2 个 k × 120 带 × 9 轨道）：

* **398/1080** 个 (k = Γ) 的 (带, 轨道) 组合上，9 个副本**并不全相同**，最大差 **0.713**；
* **469/1080** 个 (k = 0.1) 的组合同样如此；
* 例：band 82 的 dz2 分量上，9 个副本取 **3 个值**（各 3 次），按 **`(m+n) mod 3`** 分组
  —— 这是超胞内三重对称的等价类，**不是**"连续 3 个离子一组"。

⇒ **不可**取单个副本、**不可**假设副本相等；必须做相位还原的副本平均
`p_i = (1/N)·Σ_T c_{i+T,lm}·exp(±i(k'−K)·T)`。原型 `unfold_procar.py` 即如此。

### 6.3 副本平移 T 的计算：必须在笛卡尔下做

```
T = [(q·A_sc − p·A_prim)·A_sc⁻¹] · M_eff
```

分数坐标直接相减会把跨胞的原子混在一起（T5 §1.3）。

## 7. 相位符号约定 s1/s2 与自检判据

### 7.1 s1 / s2 的含义

4 种组合 `CONVENTIONS = ((+1,+1), (+1,−1), (−1,+1), (−1,−1))`：

| 符号 | 作用对象 | 物理含义 |
|---|---|---|
| `s1` | 副本平移项 `exp(s1·i·(k'−K)·T)` | **原子相位因子**（副本相位还原）的符号 |
| `s2` | 原胞 k 相位项 `exp(s2·i·k'·r_i)` | **倒空间相位因子**（Bloch character）的符号 |

### 7.2 择优的**采样口径**（与已验证原型一致）

只在 **首 `min(4, n_k)` 个 k × 首 `min(n_band, 40)` 条带**上评估 4 种约定
（`CONVENTION_SAMPLE_N_K = 4` / `CONVENTION_SAMPLE_N_BAND = 40`），
选定后**单次全量**算权重 —— 开销降到约 1/4 + 1/4，口径不变。

⚠ **用"全部 k × 全部带"择优会选出不同的约定** ⇒ 费米面随之改变。评审实测（T5 §8.2/§8.6）：

| 口径 | (+1,+1) | (+1,−1) | (−1,+1) | (−1,−1) | winner | runner-up | margin | rel |
|---|---|---|---|---|---|---|---|---|
| **原型** `unfold_procar.py` 实跑 `[conv]` | 0.7660 | 0.7867 | **0.7868** | 0.7701 | (−1,+1) | (1,−1) | ~1e-4 | ~1.3e-4 |
| **模块**（原型口径） | 0.765961 | 0.786716 | **0.786788** | 0.770061 | (−1,+1) | (1,−1) | 7.15e-05 | 9.09e-05 |
| **模块**（全 k × 全带） | 0.786874 | **0.798854** | 0.798004 | 0.791208 | (1,−1) | (−1,+1) | 8.5e-04 | 1.06e-03 |

修复前后选出**不同**约定，后果（评审实测、本轮独立复算一致）：

* 候选归属在 **164/240** 个 (k, 带) 上不同；
* 全部候选槽上 `max|Δw| = 0.3937`；
* **62.1%** 的 (k, 带) 主导权重相对差 > 1e-3；
* k = 0 的每候选带数由 `[16,15,10,10,9,14,16,13,17]` 变成 `[16,16,9,10,17,13,16,14,9]`
  ⇒ 重组后的能带结构（**就是费米面**）改变。

### 7.3 `DominanceReport` 与三档守卫

`DominanceReport` 字段：`scores`（4 种约定的主导度）/ `selection_score` /
`runner_up_score` / `margin` / `margin_rel` / `degenerate`，
外加每态分布 `mean` / `min` / `median` / `frac_above_good`（`DOMINANCE_GOOD = 0.85`）。

守卫三档：

| 条件 | 后果 |
|---|---|
| winner 主导度 < `MIN_DOMINANCE`（0.5） | **硬错**（抛异常，不产出文件） |
| winner 与最差完全无区分（≤ 1e-12） | **硬错**（"4 种相位约定没有区分度"） |
| `margin_rel = (winner − runner_up)/winner < MIN_CONVENTION_MARGIN_REL`（1e-3） | **UserWarning**（退化区：选择由噪声驱动 ⇒ 结果不可复现） |

聚合下限 0.5 永远是硬错；**每态**下限只在 `--strict-dominance` 打开时才是硬错
（默认关：合成 fixture 上有 10.8% 的态低于 0.5，严格版会误报；真实 VASP 数据上应当打开）。

fixture 实测（T5 §8.2/§8.4）：

```
[模块] winner=0.786788 runner-up=0.786716 margin=7.15e-05 rel=9.09e-05 degenerate=True
[模块] 每态主导度: mean=0.7980 min=0.2948 median=0.9564 frac>0.85=0.5667
[模块] valid 掩码: 有效槽 240 / 306; 补位槽 66
```

真实 VASP 数据上主导度分离明显（标准势 3×1×1：**0.8936**；半核势 3×1×1：0.8747，
见 §12），不会触发退化告警。

## 8. 对称扩展到均匀原胞网格

### 8.1 逐满网格点的映射

对每个满网格点 `i`（T6 §1.2）：

```
k_idx = full_to_k[i]                           该点折到哪个已算超胞 k
p_i   = ops.apply(ir_k_prim[ir], rot_of_full)  该点的原胞分数坐标(轨道像)
g     = candidate_g_for_k(k_super[k_idx])      该 k 的**逐 k**候选折叠矢量
j     = argmin_j 周期距离( (k_super+g_j)·M^-T , p_i )
band  = energies/weights/valid[k_idx, j]
```

### 8.2 三项运行时自检（任一不通过即抛错，不静默取错带）

1. **覆盖距离**：每个网格点必须命中一个候选，距离 < `tol`（1e-6）；
2. **候选索引一致**：用 `unfolded.k_cand[k_idx, j]` 交叉核对 —— 候选顺序一旦错位立刻被抓到
   （§5.2 的负向测试）；
3. **双射**：`(超胞 k, 候选)` 与满网格点一一对应（不多不少），匹配塌缩即报错。

外加三处入参守卫：展开结果的 k 数 ≠ `grid_map.n_k`、候选数 ≠ `det(M)`、
`n_points ≠ n_k·det(M)`（§3.4）。

### 8.3 比较必须用**周期距离**

spglib 的平移代表元带 ~3e-8 残差，取模后 `0.99999997` 与 `0.0` 是**同一个点**
（非周期距离会选错候选）。实现用 `min(|Δ|, 1−|Δ|)`（`_periodic_distance` /
`_periodic_delta`）。

### 8.4 `k_cart` 取**候选的**分数值而非轨道像

`p_i` 由 `ops.apply` 算出，内部含 `np.mod(..., 1.0)`：当真实格点是 `0.0` 而计算值是
`−3e-8` 时，`p_i` 会变成 `0.99999997` —— 直接拿它换算笛卡尔坐标会**整整差一个倒格矢**。
候选分数值 `frac = (K+g)·M⁻ᵀ` 按构造落在 `[0,1)³`，是干净的那一份 ⇒
`k_cart = frac @ b_prim`。

实测（T6 §2 自检②）：笛卡尔最大差 **4.44e-16**，分数周期距离最大 **3.33e-16**（阈值 1e-6）。

### 8.5 补位槽不得进入谱函数

`valid == False` 的槽（能量 `+inf`、权重 0）表示"该候选在这个 k 点上没有第 n 条带"。
若让它参与展宽，`exp(−(E − ∞)²/2σ²)` 会把谱函数**污染成 NaN**。
`build_spectral_function` 内部用 `np.where(valid, band_e, 0.0)` /
`np.where(valid, band_w, 0.0)` 排除；下游若对带轴做 `argmin`/求最小值，**必须**用
`valid` 掩码。

### 8.6 谱函数的定义

```
A(k,E) = Σ_n w_n(k) · exp(−(E − E_n)² / 2σ²)
```

按点分块计算（每块 ≤ 2×10⁶ 个元素），峰值内存与网格规模无关。

## 9. 费米能级 E_F 的语义

### 9.1 四种模式

| 模式 | 语义 | 需要 EIGENVAL？ |
|---|---|---|
| `auto`（默认） | 按**带隙与 DOSCAR 的 E_F 的相对位置**决定（见下） | 是（不可用时退化到 DOSCAR 的 E_F 并 warning） |
| `vbm` | 总是 VBM + `--delta` | 是 |
| `doscar` | 总是 DOSCAR 的 `E_F` | 否 |
| 数值 | 直接当作 E_F（绝对值，eV） | 否 |

`auto` 的判据（只用带隙与 DOSCAR 的 E_F 的位置关系，不需要展宽宽度）：

```
gap = CBM − VBM
gap <= gap_tol (0.05)     -> DOSCAR 的 E_F     (真金属/半金属)
VBM <= dos_ef <= CBM      -> VBM + offset      (E_F 落在带隙里 => 半导体)
否则                       -> DOSCAR 的 E_F     (E_F 在带隙外 => 金属)
```

只有 `auto` 与 `vbm` 会去读 EIGENVAL —— 用户明明白白给了 E_F，不该被一个用不上的
EIGENVAL 挡住。

### 9.2 ⚠ "带边有分数占据"**不是**金属判据

任何用了展宽的**有带隙**体系，带边的占据数都会变成 0.98 这类小数（高斯展宽与
四面体法都一样）。实测（MoS2，服务器端到端跑）：唯一的分数占据出现在 `band 27`
（occ = 0.9866..1.0267），`band 28` 空 ⇒ VBM = −2.077449、CBM = −0.465849、
gap = 1.6116 eV（明确的半导体）；但若按"有分数占据 ⇒ 金属"判，`auto` 会取 DOSCAR 的
E_F = −1.920079 eV —— 它落在**带隙中央** ⇒ 画出来的费米面是空的。

### 9.3 DOSCAR 里 E_F 的位置

`DOSCAR` **第 6 行第 4 个数**（`EMAX EMIN NEDOS EFERMI`）= E_F。

### 9.4 E_F 选取结果必须**打印**并写进输出元信息

CLI 打印 `E_F : <值> eV  (--ef <模式>, --delta <值>)`；`A(k,E).npz` 里存
`ef` / `vbm` / `cbm`；`FS.cube` / `FS.bxsf` 的头部注释里也写明 E_F。

### 9.5 CLI 的带隙自检（拒绝执行 / 只告警）

CLI 在**写任何文件之前**自检：若选出的 E_F 落在带隙里（`gap > 0.05 eV` 且
`VBM < E_F < CBM`），且 E_F 离**最近的一个态**（任意 k、任意带的能量）超过 `2×sigma`
（谱函数在该处已衰减到峰值的 13% 以下），则：

* `--ef auto` / `--ef vbm` / `--ef doscar` ⇒ **拒绝执行**：stderr 打可操作错误，
  **退出码非零，不写出任何费米面文件**；
* `--ef <数值>` ⇒ **只告警、继续**（用户明给了 E_F，是他自己的判断）。

实测（T8 §8.4.8，在**真实的坏数据**上）：

```
=== A) --ef doscar (DOSCAR 的 E_F 落在带隙中央) => 应拒绝 ===
错误: 选出的 E_F = -1.920079 eV 落在带隙内 (VBM=-2.077449, CBM=-0.465849, gap=1.611600 eV),
      离最近的态 0.157370 eV (> 2×sigma) —— 该能量上没有任何态, 产出的费米面是空的。
      半导体请用 --ef vbm (VBM+delta); 金属请检查 ISMEAR/展宽设置。已中止, 未写出任何费米面文件。
RC=1
输出目录是否被创建: ls: cannot access /tmp/_rsh/fs_doscar: No such file or directory   <-- 零输出
```

注意 `ISMEAR = 0` **修不好**这个问题（高斯展宽一样会让带边占据数变成小数）。
带隙体系的正确画法是 `--ef vbm`（VBM + delta），或用 `ISMEAR = -5`（四面体法，
占据数接近整数）。

## 10. VASP 6.6.0 相关实测事实

### 10.1 `LORBIT = 12` 的 PROCAR 结构

`LORBIT = 12` ⇒ PROCAR 首行 `PROCAR lm decomposed + phase`，每条带**两块**：

| 块 | 字段数（norb = 9 时） | 内容 |
|---|---|---|
| 模方块 | **11** = ion + 9 个轨道的 \|p\|² + tot | 模平方 |
| 复投影块 | **20** = ion + 9×(Re,Im) + \|c\|² | **(Re, Im) 交错排列**，末列 = Σ\|c\|² |

* `LORBIT = 11` **不写相位块**（读到没有复投影块的文件时解析器直接报错，消息里带
  `LORBIT=12` 提示）；
* 字段数按 `norb` 相对判定（模方块 `norb+2`、复投影 `2*norb+2`），不写死 11/20 ⇒
  换体系不会静默错读；
* 末列 Σ\|c\|² 与由解析出的复系数算出的 Σ_m\|c_m\|² 一致（实测 max **7.54e-4**），
  这是对 "(Re, Im) 交错" 解释的独立交叉校验（若按 "9×(Re,Re,…)" 分组解释，该恒等式
  立刻失效）。

### 10.2 EIGENVAL 第 6 行的语义

EIGENVAL 第 6 行 = **`NELECT NKPT NBANDS`**（**不是** `NIONS NKDIM NBANDS`）。
真实例子（T8 §8.4，标准势 Mo_sv）：

```
78      9     49        ← NELECT = 78 (3×14 + 6×6), NKPT = 9, NBANDS = 49
```

（半核势那一轮是 `54  9  39`；3×3×1 标尺体系是 `234 4 129` 与 `234 16 129`，
见 §12.7。）

### 10.3 PROCAR / EIGENVAL 的 k 点是**分数坐标**

两者**逐位相同**。若 PROCAR 打印的是笛卡尔坐标，该 fixture 的第二个 k 点应是
`(0.0657, 0.0379, 0)`（2π/Å）；实测是 `(0.1, 0.0, 0.0)` ⇒ 与 EIGENVAL 同约定。
实现统一用 EIGENVAL 的分数 k。

### 10.4 ⚠ 测试 fixture **不能**当物理基线

`tests/data/PROCAR` 的复投影系数只有 **3 位小数**、相位被量化到 **0/180°**，
且同一原胞原子的 9 个副本在部分 (带, 轨道) 上取 3 个不同值 —— 这是**刻意构造**的
测试向量（能量是物理的：Γ 点带隙 1.612 eV，与实测的 1.622 eV 一致）。

⇒ 物理基线用 master 上的**真实 VASP 数据**（§12），不用 fixture。
fixture 上的主导度分布也明显偏弱（Γ 上 4 约定平均主导度只有 0.619~0.637），
真实数据上是 0.89 上下。

### 12.7 3×3×1 标尺体系（27 原子）的实跑 —— 能力边界

| 网格 | 超胞 k 点数 | EIGENVAL 头 | 主导度 | 结果 |

| `--grid 6 6 1` | 4（2×2 采样超胞 BZ） | `234 4 129` | **0.4992** | `unfold` **拒绝**（< 0.5 硬门槛，退出码 1） |

         DOSCAR E_F = -1.37508366 ; auto E_F = -1.460947 (= VBM + 0.05)
12x12x1: VBM = -1.510566  CBM = 0.102999  gap = 1.613565 eV
         DOSCAR E_F = -1.42623744 ; auto E_F = -1.460566 (= VBM + 0.05)

⇒ 网格细不细取决于**超胞 BZ 被采样了几个点**（`n_k = ∏(P_i/M_i)`），不是原胞网格

## 13b. cube 轴序约定的**五个独立实现交叉验证**

cube 的三条约定 —— **矢量行 = 增量矢量 `b_i/n_i`**、**单位 = Bohr**、
**存储顺序 = 第 3 个轴最快**（线性下标 `i₁·n₂n₃ + i₂·n₃ + i₃`）—— 由五个
**互相独立**的实现确认（全部实测，出处见 `ledger` 的 Ruling 14 与其终局）：

| 实现 | 矢量行 | 单位 | 数据轴序 | 证据 |
|---|---|---|---|---|
| **ASE 3.26** `ase/io/cube.py` | 增量 × n | Bohr | **第 3 轴最快** | `write_cube` 写死 `OUTER LOOP: X, MIDDLE LOOP: Y, INNER LOOP: Z`（= **Gaussian 官方约定**：X 最慢 / Z 最快）；`read_cube` 的 `data.reshape((n1,n2,n3))` 是 **C 序** ⇒ 末轴最快；`cell[i] = n·Bohr·vec[i]` ⇒ 增量矢量 |
| **Quantum ESPRESSO 7.0** `PP/src/cube.f90` | 增量 | Bohr | 第 3 轴最快 | 文件头注释即格式规范（"4-6 I5,3F12.6 #GRIDPOINTS, INCREMENT VECTOR"、"ALL COORDINATES ARE GIVEN IN ATOMIC UNITS"）；写循环 `WRITE(rho(i1,i2,i3), i3=1,nr3)` |
| **V_Sim 3.8.0** `lib/plug-ins/cube/cube.c` | 增量 × n | Bohr | 第 3 轴最快 | `visu_scalar_field_data_set(rd.field, rd.density, VISU_SCALAR_FIELD_DATA_ZYX)` ⇒ **ZYX 序 = 第 3 轴最快**；`read_box()` 里 `rd->box[i][k] *= rd->mesh[i]` ⇒ 矢量行是增量矢量 |
| **VESTA 3.5.8**（主消费者） | **增量 × n** | **Bohr** | **`flat = i₁ + n₁i₂ + n₁n₂i₃` ⇒ 第 3 轴最快** | 反汇编 `libVESTA.so`：`readCUBEfile`（`sscanf("%d %lf %lf %lf")` 取 n_i 与矢量分量，随后 `cvtsi2sd n_i; mulsd <Bohr>` ⇒ 矢量按 n_i×Bohr 缩放）；`read_density_data` 的三重循环 `flat = ebp + (r15d + r14d·[0x3f4])·[0x3f0]` |
| **本项目写出**（原始字节序实测） | 同上 | 同上 | 同上 | 写出的原始值序列 == 满网格内存序（i3 最快） |

⇒ ⚠ **简报原文"体数据按 cube 顺序（x 最快）"与实测标准相反**（标准是 **z 最快 /
x 最慢**）。实现按**实测标准**做是对的，但这个偏差必须记在案上。

## 14. 已知限制（诚实清单）

1. **`grid.choose_grid_points` 的全局 LCM 过约束**（Ruling 21 只上报未改）：
   它用**全局** `comm(M⁻¹)` 约束**所有三个维度**，而对角 M 的正确条件是**逐维**
   `M_ii | P_i`。后果：对 `M = diag(3,3,1)`，P3 被强制成 3 的倍数 ⇒
   **6×6×1 网格通过 `--resolution` 不可达**（会被选成 6×6×3），3×3×1 超胞因此
   多付约 **3 倍**的 VASP 机时。**逃生口**：`unfoldfs gen --grid 6 6 1`。
   （评审实测：`P = (3,3,1)` 在数学上是自洽的 —— `n_points == n_k·det(M)` 为 True、
   `k_weight = [9]`、和 = 9 ⇒ 证明这是**过约束**而非数学必然，T8 评审 "I3" 条。）
2. **27 原子（3×3×1）超胞的展开不可靠**：6×6×1 时单 G 主导度 **0.4992**（低于 0.5
   硬门槛，被 `unfold` 拒绝）；12×12×1 时能展开，但相位约定落在退化区
   （`margin_rel = 2.74e-05 < 1e-3`）⇒ **结果不可复现**。
   **已验证的基线是 9 原子的 3×1×1 超胞**（主导度 0.8936，A 比值 0.706）。
3. **没有开自旋轨道耦合（SOC）**：INCAR 是 `ISPIN = 1`、无 `LSORBIT`。Mo 是重元素，
   SOC 会把 MoS₂ 的带隙压低约 0.15 eV ⇒ 本文的带隙数值只能当**基线**。
   实跑用的网格（27～144 个原胞满网格点）够做基线，**不够**做收敛的费米面。
4. **`FS.bxsf` 只支持 Γ 网格**：FermiSurfer 的 `read_bxsf` 结尾写死
   `for (ii = 0; ii < 3; ii++) shiftk[ii] = 0;` ⇒ **一律按 Γ 网格解释**（而
   `.frmsf` 路径有 MP 处理：`lshift == 2` ⇒ 半格偏移）。MP 网格的数据会被放到
   `i/n`，整张费米面相对 BZ **平移半个倒格矢** ⇒ 静默的错误费米面。
   ⇒ MP 网格下 CLI **跳过** `FS.bxsf` 并打印可操作的消息；其余输出
   （`FS.cube` / `band.N` / `A(k,E).npz`）对 MP 网格都成立。
5. **`FS.cube` 不携带等值面层级**：VESTA 的默认 isolevel = 0 ⇒ "画不画得出来"只
   取决于高斯尾巴是否**恰好**下溢到 `0.0`。故 cube 的头部注释写明该体数据的最大值
   与**建议层级**（≈ 最大值的一半，落在 `(0, max)` 内），例如
   `field max = 2.599e-01; use isosurface level ~ 1.299e-01`。
6. **FermiSurfer 的 `.frmsf` 携带的是相对 E_F 的能量**（`E − E_F`），
   这样用户直接打开即可（FermiSurfer 默认 `fermienergy 0.0`，写绝对能量会
   **静默画不出费米面**）。**费米速度着色是常量** —— 本模块不计算矩阵元，
   `.frmsf` 的三个矩阵元块一律写 0（确定值，不给 FermiSurfer 留未初始化内存）。
7. **CLI 的带隙自检阈值与 σ 耦合**：判据是"离最近的态 > 2σ"，用户改 `--sigma`
   会改变判定。这是有意的物理耦合（谱函数宽度就是 E_F 处的展宽），但它**不是**
   一条与参数无关的硬规则。
8. **`NBANDS` 的 ZVAL 表只是估计**：CLI 只能从 POSCAR 的元素符号估价电子数
   （内置常见元素表，未知元素按 8 计并在 INCAR 注释里注明），**不知道实际
   POTCAR 的 ZVAL**（表里 Mo = 14 只对 `Mo_sv` 势成立，半核势是 6）。
   请按 OUTCAR 的 `NELECT` 核对，或用 `unfoldfs gen --nbands <N>` 覆盖；
   `unfold` 阶段还有"最高带被占据 ⇒ NBANDS 偏小、占据态被截断"的事后告警兜底。
