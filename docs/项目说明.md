# unfoldfs 项目说明

> 超胞能带**反折叠** → 原胞布里渊区里的**能带**与**费米面**。

## 1. 动机

### 1.1 问题

要做**超胞**（莫尔/应变/缺陷/无序）的能带与费米面，就必须算超胞。但超胞的能带是
**折叠**的：超胞第一布里渊区体积是原胞的 `det(M)` 倍，`det(M)` 条原胞带全部塞进超胞的
一个布里渊区里。直接拿超胞能带画费米面，画出来的是**折叠**的费米面 —— 它是原胞费米面
在超胞 BZ 里的叠影，原胞的什么信息都读不出来。

**反折叠**（unfolding）要做的就是：把超胞的每个态按它的**投影权重**分配回原胞的 k，
重建出原胞视角下的能带与费米面。

### 1.2 与已有工具的关系

| 工具 | 做什么 | 与本项目的关系 |
|---|---|---|
| VASPKIT 282 | 能带反折叠（**平面波 WAVECAR** 路线） | 本项目走 **PROCAR 投影**路线（与 Popescu 投影同源）；两条路线没有接口（见 §5.4 的实测） |
| VASPKIT 262 | 费米面等值面（纯**能量**插值） | 本项目的费米面来自**谱权重**，262 没有"权重"的概念 |
| easyunfold | 展开能带的 Python 包 | 目标对象相同（能带）；本项目多走了一步：到**费米面**并给判据 |
| FermiSurfer / IFermi | 费米面**可视化**/生成 | 消费 `FS.cube`/`FS.bxsf`；本项目是**生产**它们的那一端，并解决"反折叠的 FS 能不能信" |

⇒ **本项目的定位**：不是"又一个反折叠工具"，而是**"反折叠结果 → 费米面"这一段**：
谱函数的正确构造（协变性）、费米面的正确提取（脊顶而非等值线）、以及**可信性的判据**。

## 2. 反折叠基本理论

### 2.1 Popescu 投影

超胞态 $\vert\Psi_K\rangle$ 在原胞态 $\vert\varphi_{n}\mathbf{k}\rangle$ 上的投影：

$$w_n(\mathbf{k}) = \langle \varphi_n(\mathbf{k})\vert\Psi_K\rangle
\times \langle\Psi_K\vert\varphi_n(\mathbf{k})\rangle$$

同一个原胞 k 可以由**多个**超胞 k（经不同的 G 分量）到达 ⇒ 权重**求和**，不是取一个。

### 2.2 候选 G 与原胞 k 的映射（行向量约定）

$$\mathbf{k}'_{\rm prim} = (\mathbf{K}+\mathbf{g})\cdot M^{-T}$$

- $\mathbf{K}$：超胞分数坐标；$\mathbf{g}$：候选整数矢量；$M$：变换矩阵（`TRANSMAT.in`）。
- **候选 G 必须逐 k 计算**（`candidate_g_vectors`）：一般 $M$ 下，逐 k 的候选集与全局
  `gset` 的**成员不同** ⇒ 用全局 gset 定索引会静默取错带。
- **比较必须用周期距离**：spglib 的平移代表元带 ~3e-8 残差，取模后 `0.99999997` 与 `0.0`
  是同一个点（非周期距离会选错候选）。

### 2.3 相位约定（s1/s2）

投影有整体相位歧义 ⇒ 每个候选 G 带一个符号 $s_1,s_2\in\{\pm1\}$。工具按**单 G 主导度**
择优；选错会让 **55 %~65 %** 的 (k,带) 换候选归属 ⇒ 整张费米面错形。
**必须报出退化告警**（winner 与 runner-up 的单 G 集中度相对差 < 1e-3 ⇒ 约定由噪声主导）。

### 2.4 满网格对称扩展与多源求和

展开结果是**按超胞 k 索引**的；本项目把它**铺回原胞的均匀满网格**：

```
g     = candidate_g_vectors(k)              该 k 的逐 k 候选折叠矢量
cand  = (K+g)·M⁻ᵀ                          候选原胞 k（落在 [0,1)³）
i     = 满网格点里周期距离最近的那个
band  = energies/weights/valid[k, j]        该 (超胞 k, 候选) 的贡献
```

一个网格点可由**多个** (超胞 k, 候选) 覆盖 ⇒ 权重按能量对齐后**求和**
（`_merge_source_bands`，同能量的带视为同一条 ⇒ 权重相加）。

### 2.5 谱函数

$$A(\mathbf{k},E) = \sum_n w_n(\mathbf{k})\,
\exp\!\left[-\frac{(E-E_n(\mathbf{k}))^2}{2\sigma^2}\right]$$

- $\sigma$：展宽（实测 0.06 eV）。
- **补位槽**（`valid=False`，能量 $+\infty$）必须排除 ⇒ 否则展宽被污染成 NaN。

### 2.6 ★ 协变性破缺与修法

展开得到的谱权重在晶体点群下**天然不协变**：对称相关的两个 k 点，谱函数可以差到 **100 %**
（一个谱峰被映到 0）。**能带能量不受影响**（对称相关点的带能量吻合到 8e-6 eV）⇒
缺陷**纯在权重里**。

- **机制**：Popescu 副本平均用的是**一个代表原子**的位置；对称操作把代表原子映到另一个
  原子（附带原胞晶格平移 $\Delta_i$）时，相位多出 $(\mathbf{k}'-\mathbf{K})\cdot\Delta_i$ 项。
- **修法**：按**原胞完整点群**做轨道平均（投影到对称不变子空间）。
  ⚠ 必须用**原胞**完整点群（12 个操作），不是"原胞∩超胞"的公共子群（4 个）——
  后者**恢复不了**六重对称。

### 2.7 ★ 反折叠费米面的提取（本文的另一个要点）

**费米面 = $E_b(\mathbf{k})$ 恰过 $E_F$ 的那条线。**

⚠ **不能**用 $A(\mathbf{k},E_F)$ 的等值线：$A$ 在费米面处是一条**高斯脊**（脊高 = $w$，
垂直宽度 $\propto\sigma/|dE/d\mathbf{k}|$），**任何低于脊高的等值线都给出脊两侧各一条**
（"两壁"），真费米面在**脊顶**。实测（1H-NbSe₂ 沿 Γ–M 切线）：两壁在 0.4543 / 0.5127，
脊顶在 **0.4830**（= 两壁中点 0.4835）。

追踪"过 E_F 的带"需要三道闸门（缺一不可）：

1. 峰必须是**真的局域极大**（$A[j-1] < A[j] > A[j+1]$）—— 否则会把"搜索窗口边缘上强带的
   尾巴"当成峰；
2. 模糊后只保留 $|E^*(\mathbf{k})-E_F| < 0.25$ eV；
3. **$E_F$ 处确实有谱权重**（$A(\mathbf{k},E_F) > 0.02\cdot\max$）。

违反 ⇒ 画出**孤零零的小圈**（实测那些圈上 $A(\mathbf{k},E_F)=0$，谱权重全在别处）。

                 ┌──────────────┐

## 4. 程序模块

`unfoldfs/` 共 8 个模块，依赖是单向的（下层不 import 上层）：

```
geometry.py   结构解析 / 变换约定探测 / 候选 G / 公共对称集
     │             (read_poscar, reciprocal, resolve_transform, candidate_g_vectors,
     │              primitive_symmetry_ops, rotation_inverse)
     ▼
grid.py       均匀网格 / 对称轨道分解 / k 点去重 / KPOINTS 写出
     │             (GridSpec, build_grid_map, primitive_grid_points, write_kpoints)
     ▼
vaspio.py     EIGENVAL / DOSCAR / PROCAR(LORBIT=12) 解析
     │             (BandData, read_eigenv, read_procar)
     ▼
unfold.py     Popescu 投影展开 / 副本相位还原平均 / 候选重组
     │             (unfold_supercell, candidate_g_for_k, build_atom_copies)
     ▼
expand.py     对称扩展到均匀网格 / 谱函数 A(k,E)
     │             (expand_to_full_grid, build_spectral_function,
     │              symmetrize_spectral_function, full_point_group)
     ▼
fsout.py      FS.cube / FS.bxsf / band.N / A(k,E).npz 写出
     │             (write_cube, write_bxsf, write_fermisurfer_bands,
     │              write_spectral_npz, select_fermi_energy, has_fermi_crossing)
     ▼
band.py       KPATH.in 解析 / 展开能带组装 / vaspkit 四件套写出 / 画图
     │             (read_kpath, path_to_super_k, assemble_band,
     │              write_band_dat, write_grd, write_klabels,
     │              _band_figure_colors, band_spectral_function)
     ▼
cli.py        gen / unfold / band / info  (只有它做 I/O 与参数解析)
```

**关键数据流**：`gen` 产出 `grid_map.npz` → VASP 读 `KPOINTS` 算 → `unfold` 读 `grid_map.npz`
+ VASP 输出 → `expand` 把展开结果**铺回满网格** → `fsout` 写文件。
⇒ **`grid_map.npz` 与 `KPOINTS` 必须出自同一次 `gen`**（否则点序对不上，`unfold` 会直接报错）。

## 5. 功能

### 5.1 `unfoldfs gen` —— 生成网格与 VASP 输入

按 `TRANSMAT.in` 探测变换、在**原胞**的均匀满网格上选点、写出 `KPOINTS`（显式点表）、
`INCAR.suggested`、`POSCAR`、`PRIMCELL.vasp`、`TRANSMAT.in`、`grid_map.npz`。

- `--grid n1 n2 [n3]`：显式网格；`--resolution`：按超胞 BZ 的采样密度自动选点。
- `--grid-type gamma|mp`：Γ 网格（`FS.bxsf` 只支持这个）/ MP 网格。
- `--nbands`：实测 NBANDS（内置价电子表**没有 Ta**，必须按 `OUTCAR` 的 NELECT 核对）。

### 5.2 `unfoldfs unfold` —— 反折叠并写费米面文件

读 `grid_map.npz` + VASP 输出 → 投影展开 → 铺回满网格 → 谱函数 → 写四种输出。

- `--ef auto|vbm|doscar|<数值>`：`auto` 的判据是**有带跨过占据阈值 0.5**（金属），
  而不是"表观带隙"（有限 k 网格的采样假象：网格加密 4 倍，1T-TaS₂ 的表观 gap
  0.209156 → 0.072827）。
- `--no-symmetrize`：关掉轨道平均（**默认做**）。

### 5.3 `unfoldfs band` —— 沿 k 路径做展开能带

两阶段：阶段 1 生成 `KPATH.in`/`KPOINTS`/`INCAR.suggested`/`KLABELS.in`；阶段 2 读 VASP 输出
→ 组装展开能带 → 写 vaspkit 四件套 + 长表 + PNG。

### 5.4 `unfoldfs info` —— 网格与对称信息

打印网格规格、满网格点数、对称轨道分解、超胞变换、NBANDS 估值。

### 5.5 实测：VASPKIT 的两个模块与费米面**没有交点**

1. `vaspkit -task 282` 在只有 INCAR/KPOINTS 的目录报 `The WAVECAR File NOT Found`
   ⇒ 282 走**平面波 (WAVECAR) 展开**，不是 PROCAR 投影展开；
2. `vaspkit -task 262` 的日志只读 `EIGENVAL`（能量）+ `DOSCAR`（费米能级），
   纯能量插值出等值面，**没有任何展开权重的概念**；
3. 把手写网格 KPOINTS + 网格映射表喂给 282：流程能跑完，但 `WEIGHT.grd` /
   `MOMENTUM.grd` **全为 0** ⇒ 网格模式不可用。

⇒ 不是操作问题，是两个模块**没有接口**。

## 6. 使用方法

### 6.1 安装

```bash
pip install -e .            # 或 pip install '.[plot]'（带 matplotlib 的画图依赖）
```

### 6.2 典型工作流

```bash
# ① 生成网格与 VASP 输入
unfoldfs gen --supercell sc3x1x1/POSCAR --primcell PRIMCELL.vasp \
             --transmat TRANSMAT.in --grid 48 48 1 --nbands 40 --outdir run/

# ② 跑 VASP（INCAR.suggested 改名成 INCAR；**必须 ISYM = 0**）

# ③ 反折叠 → 费米面文件
unfoldfs unfold --dir run/ --ef auto --outdir fs/
#   → fs/FS.cube  fs/FS.bxsf  fs/band.1 ...  fs/A(k,E).npz

# ④ 展开能带（沿路径）
unfoldfs band --kpath KPATH.in --dir run/ --outdir band/ --ef auto

# ⑤ 出图（出版级）
DATA=<数据目录> OUT=<输出目录> bash scripts/figures/make_final_figures.sh
```

### 6.3 出图脚本

| 脚本 | 画什么 |
|---|---|
| `scripts/figures/plot_band.py` | 展开能带图（原胞蓝线 + 超胞热图） |
| `scripts/figures/plot_fs.py` | 费米面图（真费米面 + 权重配色），`--split-dir` 出单面板小图 |
| `scripts/figures/plot_fs_3d.py` | 三维费米面（PyVista/VTK；`sheet`=物理版、`tube`=权重版） |
| `scripts/figures/plot_fs_kz.py` | 任意 kz 切片的 kx-ky 费米面（多切片并排） |
| `scripts/figures/check_fs_symmetry.py` | 核对费米面图的对称性（几何 + 颜色） |
| `scripts/figures/setup_fs_kz.sh` | 服务器端：带 kz 采样的费米面算例 |

图内文字支持 `--lang zh|en`（论文图用 `en`）。

## 7. 两个端到端案例

### 7.1 1T-TaS₂（金属、单层）

**结构**：1T-TaS₂ 单层 + 17.66 Å 真空（c 轴）；面内六方。
**算例**：12×12×1 与 48×48×1 网格；超胞 3×1×1（9 原子）与 √3×√3 R30°（9 原子）；
VASP 6.6.0。

**关键数字**（详见 README §4b 与 `algorithms.md` §9.8）：

| 项 | 6×6×1 | 12×12×1 |
|---|---|---|
| NELECT / NKPT / NBANDS | 51 / 12 / 40 | 51 / 48 / 40 |
| DOSCAR 的 E_F | −1.377658 | −1.460379 |
| 表观 VBM/CBM（**假带隙**） | −1.568592 / −1.359436（0.209156） | −1.471216 / −1.398389（0.072827） |
| `--ef auto` 选出 | −1.377658（= DOSCAR ✓） | −1.460379（= DOSCAR ✓） |
| A(E_F)/A_max | 0.8770 | 0.9839 |
| 单 G 主导度 | 0.9035（未退化） | 0.966864 vs 0.966714（相对差 1.55e-4 ⇒ 退化区告警） |

**结论**：费米面非空（带 25/26/27 跨过 $E_F$）；协变性缺陷实测 **1.000e+00 → 0.000e+00**
（完整点群轨道平均后）；与原胞直算的 $A(\mathbf{k},E_F)$ 相关 Pearson **0.313 → 0.720**。

### 7.2 1H-NbSe₂（单层）

**结构**：1H-NbSe₂ 单层（a = 3.442 Å）。
**算例**：48×48×1 网格（原胞直算 + 3×1×1 + √3×√3 反折叠）；σ = 0.06 eV。

**结论**：
- 真费米面 = Γ 附近的六边口袋 + 6 段 M 点附近的弧；
- **两壁 vs 脊顶**：沿 Γ–M 切线，$A(\mathbf{k},E_F)$ 的 0.5·max 等值线在 0.4543 / 0.5127，
  真费米面在 **0.4830**；
- **验证**：反折叠 FS 与原胞直算 FS 的距离中位 **1e-5 格**（3×1×1）/ **4.3e-4 格**（√3×√3），
  最大 0.000 / 0.008 格 ⇒ **100.00 % 重合**；
- **对称残差**：颜色 2.2e-16（TaS₂）/ 2.3e-12（NbSe₂）；几何中位 0.0001 格。

### 7.3 回归基线：MoS₂（半导体）

展开后带隙 **1.622165 eV** 与已知 MoS₂ 带隙一致 ⇒ 公式与相位约定正确。
⚠ 但 MoS₂ 是半导体，**没有费米面**：`--ef auto` 给的是**价带顶的 Hofmann 面**
（$A(E_F)$ 峰值比 0.706）。

### 7.4 1T-TaS₂ 的 CDW 态(体相, 39 原子)

**用用户自己的 CDW 计算**(服务器 `/data/wjlu/work/vasp_work/TaS2_CDW_phonon/A/band`;
另有 `AA_sliding` 态): 体相 1T-TaS₂, 26 S + 13 Ta = 39 原子, GGA + rev-vdW-DF2,
ENCUT=500, 无 SOC。CDW 指纹: Ta-Ta **3.165 Å**(三聚体内) vs 3.473-3.507 Å(聚体间),
原胞 Ta-Ta = 3.3574 Å ⇒ **三聚化收缩 5.7%**。

**能隙(已有 EIGENVAL 实测)**: 141 个 k 点**全部绝缘**; **直接能隙中位 0.48 eV**
(最小 0.22 eV); **间接能隙只有 0.018 eV** ⇒ CDW 态是**窄隙半导体**
(FERMI_ENERGY 文件取 VBM 5.353 eV)。

反折叠需要的文件由 `scripts/cdw/build_bulk_cdw_prim.py` 生成:
`PRIMCELL.vasp`(3 原子)/ `TRANSMAT.in` / `IDEAL_SUPERCELL.vasp`(未畸变, 同原子顺序)。

**三个坑**:
1. **M 的取向**: det(M)=13 有 24 个等价取向, 必须挑"CDW 的 Ta 离理想格点偏移最小"的
   那个(实测 `M = [[-4,-1,0],[1,-3,0],[0,0,1]]` ⇒ Ta 偏移 <=0.23 Å, S <=0.11 Å)。
   挑错取向 ⇒ "理想结构"整体差 ~2 Å, 原子对应全错。
2. **S 的上下关系不能假设**: 这版 CDW 的 S 在 (1/3,2/3) 子晶格的那层更靠下 ——
   与标准 1T 相反。必须按子晶格分类取平均 z。
3. **原子对应要用未畸变的超胞**(CDW 把原子挪开了, 严格匹配失败):
   `--supercell <IDEAL_SUPERCELL.vasp>`。

算例: `run_cdw39_band`(作业 100859, isspfml03, 1 节点 x 64 rank, ~12 min, ISYM=0,
180 带, **原胞基**的 Γ-M-K-Γ | Γ-A-L-H-A 路径 20 点/段 = 132 k 点)。

**反折叠阶段的三个坑**:
1. **PROCAR 必须 LORBIT=12**(11 不写相位 ⇒ 报"PROCAR 中没有复投影块"), 11 只是 DOSCAR。
2. **展开被主导度自检挡住**: CDW 态的单-G 主导度 **0.4860 < 0.5** ⇒ 工具直接报错。
   物理原因: **CDW 态不是原胞平移的本征态**, 态被摊到多个候选 G 上(金属态 0.74)——
   不是数值问题。跑通的办法: 复制一份包把 `MIN_DOMINANCE` 放宽(`pkg_r19` 里设 0.35)。
3. **原子对应用未畸变的超胞**(`--supercell IDEAL_SUPERCELL.vasp`): CDW 把原子挪开了。

**结果**: 展开后的谱**保留能隙**(A(k,E_F) 中位 0.00000, 谱权重标度 ~0.8/k), 但主导度
只有 0.49 ⇒ 展开谱是**涂抹过的**表示; CDW 区的本征能带(直接隙 0.48 eV)才是更忠实的描述。

**出图注意**: CDW 图必须**单栏**(`paper_fig_cdw.py --width 3.4`)—— 全栏 `figure*` 会被
LaTeX 推到讨论之后(这正是"最后一个图跑很靠后"那个毛病)。


## 8. 出图约定与已知坑

完整清单见 [`scripts/figures/README.md`](../scripts/figures/README.md)，最关键的几条：

1. **费米面画 $E_b = E_F$ 的轨迹**，不画 $A(\mathbf{k},E_F)$ 的等值线（后者是"两壁"）；
2. **颜色 = 过 $E_F$ 那条带的谱权重**，按**原胞完整点群**轨道平均；原胞面板用蓝线；
3. **轨道平均要把「原点」的值加到「像」上**（`field.ravel()`），写成 `field[i2,j2]` 就退化成恒等；
4. **取色插值必须点群协变**：倒格矢基不正交、C3 在分数基里是剪切型 ⇒ 双线性插值
   在对称相关点上给出不同的值（残差达场值跨度的 10 %）⇒ 用**笛卡尔等距高斯核**（残差 → 1e-16）；
5. **LineCollection 的颜色数组必须"一段一个"**（取段中点）：否则颜色沿曲线整体错位
   （1T-TaS₂ 权重变化快 ⇒ 明显；1H-NbSe₂ 变化慢 ⇒ 几乎看不出 —— **同一 bug 在两个材料上表现不同**）；
6. **核对对称性要用"点到线段"距离**，别用"光栅化比像素"（亚像素位移就整片翻红）。

## 9. 已知限制（务必读）

完整清单见 README §7。最要紧的几条：

1. **对称化是投影，不是物理** ⇒ **绝对**形状（口袋面积、各向异性）不可当定量结果用；
2. **残余差异是超胞本身带来的**（3×1×1 超胞的能带与原胞不同），不是对称化能消除的；
3. **没有开 SOC**（`ISPIN = 1`）⇒ 带隙数值只能当基线，不能与实验直接比；
4. 实跑的网格够做基线，**不够**做收敛的费米面；
5. **27 原子（3×3×1）超胞的展开目前不可靠**；已验证的基线是 **9 原子的 3×1×1 超胞**；
6. **逐带文件（`FS.bxsf` / `band.N` / npz 的 `band_e`,`band_w`）不做对称化**；
7. **FS.bxsf 只支持 Γ 网格**；
8. 现有算例是 **2D k 网格**（只有 kz = 0）⇒ 三维 FS 只是二维 FS 沿 kz 的拉伸
   （单层体系 kz 无色散，层间耦合 ≈ e^{-c/3} ≈ 0.003）；
9. 权重绝对值**不守恒**。

# 0) 环境

             --transmat TRANSMAT_identity.in --grid 48 48 1 --nbands 20 --outdir run48_prim/

             --transmat TRANSMAT.in --grid 48 48 1 --nbands 40 --outdir run48_sc3x1x1/

  unfoldfs unfold --dir run48_$t --ef auto --outdir fs96_$t
done

DATA=<数据目录> OUT=<输出目录> bash scripts/figures/make_final_figures.sh
